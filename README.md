# 路灯调光能耗审计台


替代 Excel 台账的单页能耗核算工具：纯前端（无框架、无构建），Node 20 零依赖静态服务。

## 运行

```bash
node server.js          # 默认 http://localhost:8080/
```

重新生成样例数据 / 跑验收自检：

```bash
node tools/gen-sample.js   # 生成 data/lamps.json、data/curves.json（100 灯 / 12 回路）
node tools/verify.js       # 35 项无头验算（审计、日数、能耗手算对照）
```

## 数据

- `data/lamps.json`：回路多边形（WGS84 经纬度）+ 灯具台账（编号、所属回路、经纬度、功率 W、光源类型、投运日期）。
- `data/curves.json`：电价（0.62 元/kWh）、计划亮灯时段、调光曲线（分时段亮度百分比，支持跨午夜）、回路-曲线指派（一条曲线可套多条回路，按生效日期区间）。

## 计算口径

- **折算方式：亮度百分比线性折算**（页面顶部与底部均有注明）。功率 = 额定功率 × 亮度%，不做光通量/视觉补偿。
- 单灯单日能耗 = 功率(kW) × 当日等效满功率小时（Σ 时段时长 × 亮度%）。
- 日数按真实日历逐日累计，跨月分月统计；2 月 28/29 天、大小月按实际；投运日之前不计（含投运首日）。
- 亮灯率 = 实际点亮小时 ÷ 计划亮灯小时（亮度 0% 时段不计点亮）。
- 同一回路同一时刻多条生效曲线：审计栏报错，计算取 startDate 最晚一条。

## 验收路径

1. `node server.js` 打开页面，审计栏应列出 6 条问题（L10 曲线重叠 15 天、3 盏灯落在 L12、1 盏落在 L07/L08 重叠带、1 盏在回路外）。
2. 默认窗口 2025-01-15 ~ 2025-03-15（60 天，跨 1/2/3 月，2 月按 28 天）。
3. 点击地图回路（如 L01），在右侧面板把方案 B 的该回路曲线改一档（如 ECO → DEEP），两张方案卡与对比表同步重算，L01 行能耗差随之变化。
4. 点击任意灯点，弹窗给出该灯两套方案的逐步演算（曲线时段 → 等效满功率小时 → kWh → 电费 → 亮灯率 → 分月天数），可逐步核对。

## 文件

- `server.js` 零依赖静态服务（含路径穿越防护）
- `index.html` / `styles.css` / `app.js` 单页应用（计算引擎在 `app.js`，可被 `tools/verify.js` 复用）
- `tools/gen-sample.js` 样例数据生成器（确定性随机，可复现）
- `tools/verify.js` 验收自检
